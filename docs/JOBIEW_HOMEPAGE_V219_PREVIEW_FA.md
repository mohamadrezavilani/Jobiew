# Jobiew v2.0.19 — پیش‌نمایش یکپارچهٔ صفحهٔ اول

## منشأ و محدوده

طرح مبنا همان فایل ارسال‌شدهٔ `jobiew_homepage_standalone.html` است. ساختار کلی، رنگ‌ها، لوگوهای SVG، نوار اصلی، جست‌وجو، نقشه/فهرست، تب کاری/مصاحبه، فیلتر جانبی و فوتر حفظ شده‌اند. فونت‌های WOFF2 تعبیه‌شده در فایل ماک‌آپ به مخزن منتقل نشده‌اند؛ CSS فونت موجود پروژه استفاده می‌شود. کد HTML/CSS/JS نمونه به‌صورت مستقیم و بدون بررسی به صفحهٔ عمومی اضافه نشده است.

**چرا صفحه روی `/` جایگزین نشده؟** ماک‌آپ دارای ۱۲ شرکت با شماری نام فرضی، نمره و نمودار و مکان‌های نمایشی بود. پیاده‌سازی جدید فقط دادهٔ آرشیوی همان مدل `Company` و API عمومیِ نقاط دارای تأیید مستقل را می‌خواند. صفحهٔ اصلی فعلی تا پذیرش محصول دست‌نخورده می‌ماند.

## تغییرات

- مسیر مستقل: `/internal/homepage-preview/`؛ تنها GET، read-only، کاربر فعال staff با مجوز `companies.view_company` و فعال‌سازی صریح.
- جست‌وجوی سمت سرور، مرتب‌سازی واقعی بر اساس شمار تجربهٔ کاری/مصاحبه، دو تب مستقل، صفحه‌بندی ۲۴تایی، فیلتر راستی‌آزمایی هویت/فناوری/تهران و فقط دارای تجربه.
- نقشهٔ MapLibre با OpenFreeMap و API `verified-company-locations` موجود: پین فقط در صورت تأیید مستقل و فقط برای شرکت‌های همین صفحه، بدون مکان فرضی. نبود نقاط به‌صراحت اعلام می‌شود.
- ۶ معیارِ مرتبط با تب از registry رسمی می‌آیند؛ نمره‌های ساختگی و نمودارهای پر حذف شده‌اند. نمودارهای خالی «نمره صفر» نیستند. هیچ `CriteriaAnalysis`، دادهٔ خصوصی یا نتیجهٔ تأییدنشده به صفحه نمی‌رود.
- لینک‌های فعال به جزئیات شرکت، نقشه و بخش‌های توضیحی واقعی ارجاع داده شده‌اند. عملکردهای ساختگی مثل ورود/ثبت تجربه و مقایسهٔ نمرهٔ انتشارنیافته، عمداً فعال نشده‌اند.
- دسترس‌پذیری: ناوبری با کلید، بستن Escape، مدیریت فوکوس در drawer، متن جایگزین، حالت بدون نقشه، نمایش موبایل و `prefers-reduced-motion`.

## راه‌اندازی فقط برای تست

برای توسعهٔ محلی با `DJANGO_DEBUG=1`، کلید `JOBIEW_HOMEPAGE_PREVIEW_ENABLED=1` لازم است و کاربر باید staff با مجوز مشاهده شرکت باشد. برای staging با `DEBUG=False`، هر چهار شرط مستقل زیر لازم‌اند:

```
JOBIEW_HOMEPAGE_PREVIEW_ENABLED=1
JOBIEW_HOMEPAGE_STAGING_ENABLED=1
JOBIEW_HOMEPAGE_STAGING_HOST=your-dedicated-staging.example
JOBIEW_DUAL6_PUBLICATION_ENABLED=0
```

در staging باید HTTPS واقعی با پیکربندی صحیح trust-proxy فعال باشد؛ host دقیقاً باید با مقدار تنظیم‌شده برابر باشد. این تنظیمات را **هرگز روی دامنهٔ عمومی production** به کار نبرید. مسیر داخل `internal/` قرار دارد و پاسخ `private, no-store` و `noindex` دارد.

## دستورات تست

```bash
cd backend
python manage.py check
python manage.py makemigrations --check --dry-run
python manage.py test companies.test_homepage_preview_v219 -v 2
python manage.py test companies.test_company_ui_v23 companies.test_public_map_v24 criteria_v2 -v 1
```

این تغییر هیچ migration، فایل دیتابیس، تماس مدل پولی یا امتیازدهی جدیدی ندارد. پیش‌نمایش HTTPS عمومی برای مالک، بکاپ و rollback تولیدی و بازبینی روی سرور همچنان مراحل مستقل‌اند. انتشار واقعی نمره‌ها نیازمند تأیید حقوقی/معنایی و رضایت صریح مالک است.
