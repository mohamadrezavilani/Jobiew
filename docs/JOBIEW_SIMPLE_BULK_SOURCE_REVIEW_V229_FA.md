# Jobiew v2.0.29 — تأیید گروهی ساده با موارد انتخابی پیش‌فرض

## علت تغییر
در صفحهٔ بررسی گروهی مدارک اسنپ، کاربر مجبور بود تک‌تک ۳۴ ردیف و چهار تیک را علامت بزند؛ انتخاب گزینهٔ مجوز انتشار بدون لینک سند مستقل خطای نامفهوم `EXPLICIT_RIGHTS_DOCUMENT_REQUIRED` می‌داد. این صفحه باید «بررسی عادی» را از «مجوز حقوقی» روشن و جدا کند.

## تجربهٔ جدید
- همهٔ ردیف‌های **واجد شرایط بررسی گروهی** در بارگذاری اولیهٔ فرم از قبل انتخاب هستند؛ موارد صریحاً مسدودشده، ردشده یا تکراری نه قابل انتخاب و نه پیش‌انتخاب هستند. هر ردیفی که هنوز واقعاً بازبینی نشده، قبل از ارسال باید از انتخاب خارج شود. این انتخاب ظاهری **هیچ رویدادی ثبت نمی‌کند**.
- حالت اصلی با یک دکمهٔ `ثبت بررسی‌های عادی (بدون تأیید مجوز انتشار)` و **یک تیک گواهی بررسی انسانی** کار می‌کند. این حالت به‌صورت پیش‌فرض فقط `classification`، `attribution` و `independence` را برای تجربه‌های انتخابی ثبت می‌کند و هرگز `copyright` را ثبت نمی‌کند.
- اگر فقط یکی از سه مورد بالا واقعاً بررسی شده، منوی پیشرفته اجازه می‌دهد به `classification`، `attribution` یا `independence` محدود شود.
- متن توضیح اضافی اختیاری است. در صورت خالی بودن، در هر رویداد یک متن کوتاه مبتنی بر **اظهار صریح انسانی در همان درخواست** ثبت می‌شود؛ مدرک یا مجوز ساختگی ساخته نمی‌شود.
- بررسی حقوق انتشار **یک بخش مجزای اختیاری و بسته** در پایین همان فرم است و هیچ‌گاه پیش‌انتخاب نیست. فقط با انتخاب دکمهٔ `ثبت فقط مجوز منبع`، سند HTTPS مستقل، همان تیک تأیید انسانی و احراز صحت محدودهٔ مجوز روی همهٔ رکوردهای انتخاب‌شده می‌توان آن را ثبت کرد. لینک خود تجربه یا HTTP کافی نیست. بدون سند، هیچ اتفاقی برای حوزهٔ copyright نمی‌افتد.
- خطای حقوق انتشار به‌جای متن خام `EXPLICIT_RIGHTS_DOCUMENT_REQUIRED` با پیام فارسی قابل فهم و راهنمای استفاده از «ثبت بررسی عادی» نمایش داده می‌شود و انتخاب ردیف‌ها و ورودی کاربر حفظ می‌شود. پاسخ HTTP 400 است؛ هیچ رکوردی در وضعیت نامعتبر ذخیره نمی‌شود.
- کنترل‌های قبلی: محدودیت هر درخواست تا ۱٬۰۰۰ تجربه، مجوز staff، admin CSRF، HTTPS، locking، snapshot، حفاظت از شرکت دیگر/پرونده ردشده، تجدیدنظر در منبع، رویدادهای append-only و فرایند جداگانهٔ انتشار شرکت بدون تغییر حفظ می‌شوند.

## معنا برای اسنپ
۳۶ پروندهٔ امتیاز GPT-6 بازبینی‌شده‌اند؛ ۳۴ مورد عددی و ۲ مورد بدون شاهد دارند. بعد از نصب این نسخه، ۳۴ ردیف در صفحهٔ مدارک به‌صورت پیش‌فرض انتخاب می‌شوند (به‌جز هر ردیف صریحاً ردشده). برای ثبت سه حوزهٔ غیرحقوقی پس از بررسی واقعی، یک تیک گواهی بررسی و یک کلیک «ثبت بررسی عادی» کافی است. برای حقوق منبع همچنان باید سند جداگانهٔ واقعی وجود داشته باشد؛ در صورت نبود آن، ۰ مورد قابل انتشار می‌تواند همچنان درست باشد. **این تغییر امتیازها را به‌طور خودکار عمومی نمی‌کند.**

## استقرار
بدون migration یا ورود مجدد ZIP. پس از موفقیت CI نسخهٔ مرج‌شده:

```bash
set -euo pipefail
sudo -u jobiew git -C /opt/jobiew fetch origin main
sudo -u jobiew git -C /opt/jobiew pull --ff-only origin main
test "$(systemctl show -P WorkingDirectory jobiew-web)" = "/opt/jobiew/backend"
sudo systemd-run --unit="jobiew-v229-check-$(date +%s)" --wait --pipe --collect \
 --uid=jobiew --property=EnvironmentFile=/etc/jobiew/jobiew.env \
 --working-directory=/opt/jobiew/backend /bin/bash -c \
 '/opt/jobiew/.venv/bin/python manage.py check && /opt/jobiew/.venv/bin/python manage.py makemigrations --check --dry-run && /opt/jobiew/.venv/bin/python manage.py collectstatic --noinput'
sudo systemctl restart jobiew-web
sudo systemctl is-active --quiet jobiew-web
```
