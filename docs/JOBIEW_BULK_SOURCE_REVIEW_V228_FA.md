# Jobiew v2.0.28 — بازبینی گروهیِ مدارک تجربه‌ها، جدا از نمره‌ها

## وضعیت درخواستی
در ادمین اسنپ، ۳۶ تحلیل GPT-6 بازبینی خصوصی شده‌اند؛ ۳۴ پرونده نمرهٔ عددی دارند، ۲ پرونده بدون شاهد عددی‌اند و هر ۳۴ نمرهٔ قابل ارزیابی هنوز چهار شرط مستقل (مجوز منبع، انتساب، استقلال، دسته‌بندی) را ندارند. بنابراین ۰ نمره قابل انتشار است؛ این وضعیت به‌معنای «نبود GPT-6» نیست.

## راه ساده‌تر
صفحهٔ جدید:
`https://jobiew.ir/admin/companies/company/<company_id>/checkpoint/sources/`

از صفحهٔ انتشار هر شرکت، دکمهٔ «بررسی گروهی مدارک و دسته‌بندی این شرکت» به این صفحه می‌رود.

در این صفحه، فقط برای تجربه‌هایی که **امتیاز شش‌معیاری بازبینی‌شده و رسید تغییرناپذیر** دارند، متن کوتاه و لینک متن کامل و منبع اصلی نمایش داده می‌شود. موارد دارای `blocked`/`rejected`/`duplicate` از تأیید گروهی منع می‌شوند. کاربر باید تجربه‌های مشاهده‌شده را خودش تیک بزند (پیش‌فرض **هیچ مورد انتخاب نیست**) و از چهار داوری مستقل موارد واقعاً بررسی‌شده را مشخص کند:
1. دسته‌بندی (work/interview) پس از خواندن روایت
2. انتساب به شرکت با ارجاع به منبع
3. استقلال و تطبیق تکراری‌ها پس از بررسی انسانی
4. مجوز استفاده از محتوای منبع برای **انتشار امتیازهای تحلیلی مشتق‌شده**؛ این مورد نیازمند **سند مستقل HTTPS** و تأیید محدودهٔ حقوقی برای تمام تجربه‌های انتخاب‌شده است. لینک خود تجربه مدرک حقوق انتشار نیست. این ابزار محتوای اسناد خارجی را خودکار اعتبارسنجی نمی‌کند؛ مسئولیت بررسی صحت و شمول سند بر عهدهٔ بازبین است.

یک توضیح کوتاه گروهی ثبت می‌شود و برای هر تجربه/حوزهٔ تأیید، رویداد audit مستقل با نام بازبین و سند مربوط ساخته می‌شود. رویدادهای قبلی و امتیازها تغییر نمی‌کنند. در پایان به صفحهٔ انتشار شرکت برمی‌گردی و تعداد موارد دارای مدرک کامل به‌صورت تازه محاسبه می‌شود.

**هیچ تصمیم انتشاری با این فرم ساخته نمی‌شود.** تنها از صفحهٔ انتشار نهایی، با تأیید مالک، می‌توان مجموعهٔ ثابت نمره‌های مجاز را منتشر یا متوقف کرد. در غیاب مجوز واقعی، کادر مجوز را انتخاب نکن؛ نمره‌ها خصوصی باقی می‌مانند. استفاده از پرچم‌های عمومی برای دور زدن مجوز ممنوع است.

## پیاده‌سازی و ایمنی
- URL گروهی از Django Admin و `admin_site.admin_view`، احراز هویت خصوصی HTTPS، مجوزهای ثبت رویداد منبع و دسته‌بندی، CSRF و `Referrer-Policy: same-origin` استفاده می‌کند.
- بازبینی با `transaction.atomic`، قفل شرکت و تجربه‌ها، snapshot محتوای منبع و رویدادهای قبلی، سقف حداکثر ۱٬۰۰۰ پرونده و جلوگیری از تکرار ثبت، race condition و اجرای مجدد فرم قدیمی را کنترل می‌کند.
- انتخاب‌ها باید صریح باشند و هیچ فیلد حقوقی یا انتسابی از checkpoint AI به‌صورت پیش‌فرض تأیید نمی‌شود.
- این تغییر migration ندارد، داده‌های ۲٬۲۳۴ پیشنهاد یا تأییدهای خصوصی شیپور/اسنپ را دوباره وارد/اصلاح نمی‌کند و تنظیمات انتشار را تغییر نمی‌دهد.
- ۲٬۲۳۴ پیشنهاد از ۲٬۲۴۰ ردیف پس از حذف ۶ مورد تکراری وارد شده‌اند. ۵٬۸۹۹ تجربهٔ دیگر در مجموعهٔ منبع ممکن است هنوز checkpoint GPT-6 نداشته باشند و با ثبت مدرک خودکار امتیاز نمی‌گیرند.

## استقرار
CI روی دادهٔ مصنوعی SQLite و PostgreSQL باید سبز شود. پس از مرج در `main`:

```bash
set -euo pipefail
sudo -u jobiew git -C /opt/jobiew fetch origin main
sudo -u jobiew git -C /opt/jobiew pull --ff-only origin main
test "$(systemctl show -P WorkingDirectory jobiew-web)" = "/opt/jobiew/backend"
sudo systemd-run --unit="jobiew-v228-check-$(date +%s)" --wait --pipe --collect \
  --uid=jobiew --property=EnvironmentFile=/etc/jobiew/jobiew.env \
  --working-directory=/opt/jobiew/backend /bin/bash -c \
  '/opt/jobiew/.venv/bin/python manage.py check && /opt/jobiew/.venv/bin/python manage.py makemigrations --check --dry-run && /opt/jobiew/.venv/bin/python manage.py collectstatic --noinput'
sudo systemctl restart jobiew-web
sudo systemctl is-active --quiet jobiew-web
```

برای اسنپ پس از نصب به `/admin/companies/company/c8a19a54a6e76f538acee/checkpoint/sources/` برو، مواردی که مستنداً بررسی کرده‌ای انتخاب کن و تصمیم‌های مربوط را ثبت کن. اگر مجوز حقیقی برای انتشار امتیازها نداری، با وجود تأیید سایر موارد، نمره‌ها را منتشر نکن.
