# Jobiew v2.0.20 — سوییچ کنترل‌شدهٔ صفحهٔ نخست (فقط کاندید فنی)

این تغییر صفحهٔ اول جدید را **منتشر نمی‌کند**. مسیر `/` فقط در صورت تنظیم **صریح** `JOBIEW_HOMEPAGE_PUBLIC_ENABLED=1` به طراحی جدید منتقل می‌شود. مقدار پیش‌فرض و هر مقدار غیر از `1` صفحهٔ قبلی را بدون تغییر نمایش می‌دهد.

## رفتار

- `/`: در وضعیت پیش‌فرض همان فهرست قدیمی Django؛ در وضعیت روشن، طراحی جدید با دادهٔ **هم‌اکنون عمومی و قابل فهرست** شرکت‌ها.
- `/companies/`: نشانی جایگزین ثابت و بدون شرط برای فهرست قبلی، حتی پس از سوییچ.
- `/companies/<company-id>/`: مسیر جزئیات شرکت بدون تغییر.
- `/internal/homepage-preview/`: همان پیش‌نمایش محافظت‌شدهٔ staff، با گیت مستقل؛ روشن‌کردن سوییچ عمومی **به آن دسترسی نمی‌دهد**.
- جست‌وجو، صفحه‌بندی، جابجایی کاری/مصاحبه، نقشه و فیلترها به همان queryset مجاز متصل‌اند. نمره‌های جدید یا `pilot_unverified` همچنان **هرگز** خوانده یا منتشر نمی‌شوند.
- صفحهٔ جدید در حالت عمومیِ اولیه برای جلوگیری از نمایه‌سازی قبل از تأیید تحریریه `X-Robots-Tag: noindex` دارد؛ فعال‌کردن انتشار، مجوز حقوقی منابع یا تأیید کیفیت داده‌ها نیست.
- schema و migration، اطلاعات `CriteriaAnalysis`، چهل گزارش قبلی، checkpointها و پرچم انتشار ۶+۶ تغییر نمی‌کنند.

## آزمون محلی

```bash
cd backend
JOBIEW_HOMEPAGE_PUBLIC_ENABLED=0 python manage.py test companies.test_homepage_public_v220 companies.test_homepage_preview_v219 -v 2
python manage.py makemigrations --check --dry-run
```

با سوییچ خاموش `GET /` باید قالب `companies/index.html` داشته باشد. با سوییچ روشن `GET /` قالب `companies/homepage_preview_v219.html`، لینک جست‌وجوی `/` و پیوند فهرست `/companies/` را داشته باشد، اما هیچ نمرهٔ خصوصی، عنوان متن منبع یا نمرهٔ ساختگی نشان ندهد. در هر دو حالت `/companies/` باید قابل دسترسی بماند. تست‌ها فقط با دادهٔ مصنوعی در CI اجرا می‌شوند.

## فرایند پذیرش و بازگشت

۱. قبل از هر اقدام، PR تغییرات پیش‌نیاز (`v2.0.19`)، CI و بررسی حقوق منبع را جداگانه بپذیرید. بدون کپی دیتابیس تولید، روی **staging مستقل HTTPS/VPN** با دادهٔ مجاز آزمون کنید.
۲. flag عمومی را ابتدا روی staging با تأیید صریح مالک روشن کنید. لاگ‌ها، هدرها، جست‌وجو، عملکرد موبایل، map fallback، فیلترها و عدم نشت خروجی‌های GPT-6 را بررسی کنید.
۳. برای فعال‌سازی تولید، تأیید مجزای مالک برای **تغییر تجربهٔ صفحهٔ اول**، بکاپ تست‌شده و rollback لازم است؛ مرج کد به‌تنهایی مجوز آن نیست.
۴. rollback فوری: `JOBIEW_HOMEPAGE_PUBLIC_ENABLED=0` در فایل محیط محرمانهٔ همان سرویس و restart کنترل‌شدهٔ Gunicorn؛ مسیر و قالب سابق برمی‌گردد، زیرا هیچ migration یا پاک‌کردن داده‌ای رخ نداده است.
۵. بعد از تأیید حقوق و کیفیت داده‌ها، تصمیم مستقل برای برداشتن `noindex` و انتشار نمره‌ها لازم است؛ **هیچ‌کدام** توسط سوییچ صفحهٔ اول انجام نمی‌شود.

## وضعیت

پیاده‌سازی feature-gate و تست‌های مصنوعی: آمادهٔ بررسی PR و CI. استقرار staging واقعی، احراز URL/HTTPS و deploy تولید: **انجام نشده**؛ بدون دسترسی مجاز به سرور و چراغ سبز مالک انجام نخواهد شد.
