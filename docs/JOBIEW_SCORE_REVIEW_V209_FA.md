# جابیو — بازبینی انسانی امتیازهای ۶+۶ (نسخه 2.0.9)

## هدف

یک گام محدود و قابل ممیزی بین پیشنهاد AI و امتیاز قابل استفاده ایجاد می‌شود. خروجی AI به‌تنهایی هیچ مجوز انتشار نمی‌دهد؛ بازبین مسئول شش تصمیم مستقل است.

## قواعد

- صفحه خصوصی `/internal/criteria/score-review/` فقط به کارکنان دارای مجوز نمایش تحلیل و تجربه دسترسی می‌دهد.
- POST نیازمند مجوز مستقل افزودن `CriteriaScoreReviewEvent` است و با CSRF محافظت می‌شود.
- هر محور امتیازدار نیازمند تصمیم تأیید/رد انسانی است؛ محور بدون نمره فقط به‌صورت امتناع/بدون شاهد پذیرفته می‌شود.
- دقیق‌بودن نقل‌قول، اعتبار نسخه، هش منبع، نوع تجربه و وضعیت اجازه استفاده پیش از ثبت مجدداً بررسی می‌شوند.
- هر شش تصمیم همراه نام بازبین و دلیل در رکورد مستقل و تغییرناپذیر ثبت می‌شوند؛ اصلاحات بعدی باید با اجرای تحلیل جدید و رویداد جدید انجام شوند.
- تأیید یک معیار به‌معنی کفایت شش‌تایی شرکت نیست. کفایت برای هر معیار به‌طور مستقل طبق مستند MVP 1.0 و آستانه پیش‌فرض شش تجربه محاسبه می‌شود.
- انتشار عمومی همچنان با `JOBIEW_DUAL6_PUBLICATION_ENABLED=0` خاموش می‌ماند. فعال‌سازی نیازمند ارزیابی کیفیت واقعی مدل، رضایت/مجوز استفاده از منبع، فرمول تجمیع پذیرفته‌شده و پذیرش محصول است.

## نصب و بررسی

در PowerShell ریشه مخزن، پس از دریافت ZIP و قرار دادن آن در Downloads:

```powershell
Expand-Archive -LiteralPath "$env:USERPROFILE\Downloads\jobiew_review_v209_windows.zip" -DestinationPath "$env:TEMP\jobiew_review_v209_pkg" -Force
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\jobiew_review_v209_pkg\jobiew_review_v209_windows\install_v209_windows.ps1" -RepoRoot "$($PWD.Path)" -Push
```

اسکریپت تنها شاخهٔ جدید `feature/jobiew-dual6-v209-review` را ایجاد می‌کند و Django را با SQLite تستی اجرا می‌کند؛ دیتابیس اصلی، سرور Ubuntu، کرالر و API پولی بدون تغییر باقی می‌مانند. Migration جدید در Production **اجرا نمی‌شود**. برای کارکرد صفحه بازبینی در یک محیط واقعی باید Migration به‌صورت جداگانه و کنترل‌شده اعمال شود.
