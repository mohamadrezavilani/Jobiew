# Jobiew v2.0.14 — ممیزی آمادگی پردازش گستردهٔ ۶+۶

این نسخه **هیچ تجربه‌ای را امتیازدهی نمی‌کند**. هدف، جلوگیری از شروع تحلیل هزینه‌دار قبل از تعیین تکلیف حق استفاده، انتساب، تأیید دسته‌بندی و شواهد است. آزمون‌های نسخه‌های قبلی محفوظ هستند.

## دستور روی PostgreSQL توسعهٔ ویندوز

از ریشهٔ پروژه پس از نصب:

```powershell
$env:DJANGO_DEBUG='1'
$env:DJANGO_SETTINGS_MODULE='workplace_insights.settings'
$env:WI_DB_ENGINE='postgresql'
$env:PYTHONPATH="$($PWD.Path)\backend"
$env:JOBIEW_DUAL6_PUBLICATION_ENABLED='0'
python backend/manage.py plan_dual6_rollout_v214 --expected-db workplace_insights_dev --limit 20
```

اجرای برنامه روی Ubuntu یا بدون DEBUG، یا با PostgreSQL غیرمحلی، یا دیتابیس فاقد پسوند `_dev` رد می‌شود. این محافظت فنی اتصال تونل‌شده به Production را تشخیص نمی‌دهد؛ اتصال باید واقعاً توسعهٔ محلی باشد.

## معنا و اولویت دلایل

- `copyright_not_approved`: مجوز تحلیل متن تأیید نشده؛ `pending` هرگز مساوی approved نیست.
- `attribution_not_verified`: انتساب رکورد به شرکت هنوز تأیید نشده.
- `known_duplicate`: تکراری شناخته‌شده.
- `source_digest_invalid`: هش محتوا خراب است.
- `text_out_of_range`: متن آماده‌شده خارج از بازهٔ ۵۰ تا ۸۰۰۰ کاراکتر است.
- `classification_not_confirmed`: آخرین تصمیم دسته‌بندی همان منبع `confirmed` نیست یا هش آن قدیمی است.
- `already_evaluated`: برای منبع فعلی قبلاً تحلیل ثبت شده، حتی اگر پایلوت تأییدنشده باشد.
- `ready`: **فقط** هر هفت شرط بالا گذرانده شده. این حالت اجازهٔ خودکار هزینه‌کردن یا انتشار نمی‌دهد.

برای هر تجربه فقط اولین مانع گزارش می‌شود. آمار مانع‌ها جمعاً تعداد بررسی‌شده را می‌سازد و ترتیب آن‌ها بیانگر میزان کیفیت معنایی نیست. `next_batch` تنها شناسهٔ حداکثر ۲۰ مورد آماده را برمی‌گرداند؛ متن‌ها، شرکت‌ها، نقل‌قول‌ها و لینک‌ها وارد گزارش نمی‌شوند. پیش‌فرض همهٔ عملیات فقط خواندنی است.

### محدودهٔ نسخه

- معماریِ اجرای هزینه‌دار و پردازش خودکار عمدی فعال نیست: مدل نیاز به سنجش کیفیت مستقل و داده نیاز به حقوق استفاده دارد.
- هیچ نمره یا برچسبی از `pending` به `approved` تبدیل نمی‌شود.
- امتیازهای ۴۰ نمونهٔ v2.0.12 همان `pilot_unverified` باقی می‌مانند.
- آستانهٔ کفایت مستقل ۰ / ۱ تا ۵ / ۶+ تغییری نمی‌کند.
- در صورت نیاز به ادامه از شناسهٔ مشخص از `--after-id 123` و برای هر دسته از `--kind work|interview` استفاده شود.

**این نسخه صرفاً مرحلهٔ تشخیص مانع‌های واقعیِ پوشش گسترده است، نه ادعای اتمام امتیازدهی.**
