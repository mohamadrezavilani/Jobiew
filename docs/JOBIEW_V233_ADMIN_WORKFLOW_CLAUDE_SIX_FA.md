# Jobiew v2.0.33 — ساده‌سازی کل پنل مدیریت و بررسی مستقل Claude برای شش معیار

## تصمیم معماری
ورودی‌های Jobiew سه دستهٔ مستقل دارند: (۱) فایل/نظر منبع (۲) پیشنهاد شش‌معیاری GPT-6 از checkpoint (۳) تصمیم انسانی و حقوق انتشار. تأیید یک مرحله به‌معنای تأیید بقیه نیست. صفحهٔ اصلی ادمین باید مسیر مختصر را نشان دهد، ولی گیت‌ها و حسابرسی حذف نشوند.

## تجربهٔ مدیر
- خانهٔ ادمین: یک جست‌وجوی شرکت و سه مسیر اصلی. آمارهای واقعی «تجربه‌های واردشده»، «پرونده‌های ۶معیاری»، «بازبینی‌شده»، «در انتظار» از دیتابیس خوانده می‌شوند؛ تاریخچه و جداول فنی در بخش جمع‌شونده قرار می‌گیرند.
- صف شرکت‌ها: «ادامهٔ کار» پیش‌فرض است و بقیهٔ پیوندها در گزینه‌های تخصصی قرار دارند.
- صفحهٔ `/admin/companies/company/<id>/workflow/`: پنج مرحلهٔ واضح شامل دریافت نظر، بررسی شش‌معیاری، تأیید شرکت، بررسی مدارک حقوقی/دسته‌بندی، انتشار. هر مرحله از رکوردهای واقعی وضعیت «تکمیل‌شده/نیازمند اقدام» و لینک همان مرحله دارد. وضعیت مستقل نقشه زیر بخش اختیاری است. داده‌های بازبینی قبلی هرگز حذف یا خودکار تکرار نمی‌شوند.
- فهرست شرکت‌ها خلوت‌تر است (نام، خلاصهٔ تأیید، شمار تجربه‌ها، پیوند فهرست نظر و «وضعیت و قدم بعدی»). صفحهٔ اطلاعات شرکت به مسیر اصلی ارجاع می‌دهد و جداول تخصصی در بخش جمع‌شونده قرار دارند.
- فهرست نظرهای یک شرکت جست‌وجو و نوع محتوا را مقدم می‌آورد و فیلترهای حقوقی/تکراری را در جزئیات اختیاری قرار می‌دهد. صفحهٔ هر نظر شش معیار مستقل و نتیجهٔ آخرین بررسی Claude را نشان می‌دهد (در صورت وجود).
- **ورود فایل/نظر از ادمین این نسخه هنوز یک آپلود یک‌کلیکی نیست.** Import محافظت‌شده با دستورات موجود، بررسی قالب و checkpointهای ورودی و امکان استقرار امن سرور همچنان مستقل‌اند. برای داده‌های تازه باید مانند قبل بستهٔ import معتبر ارائه شود؛ تحلیل ۵معیاری به شش‌معیاری تبدیل نمی‌شود.

## Claude برای مدل ۶+۶
- برنامهٔ قدیمی `assessments.claude_validation_v111` فقط «پنج معیار» بود و اجرای آن به‌صورت عمدی غیرفعال است؛ هرگز نباید به‌عنوان بررسی شش معیار استفاده شود.
- مدل خصوصی مستقل `criteria_v2.ClaudeSixCheck` و migration `0006_claudesixcheck_v233`، به `CriteriaAnalysis` واقعی همان تجربه اشاره می‌کند. در پنلِ تجربه‌های کاری یا مصاحبه، لینک `/admin/companies/company/<company-id>/experiences/<id>/claude-six/` نتیجهٔ قبلی و مقایسهٔ GPT-6 / Claude را در **شش محور درست همان نوع** نشان می‌دهد.
- اجرا **هرگز خودکار نیست**؛ نیازمند HTTPS، دسترسی‌های ادمین و checkpoint، وضعیت واقعی تحلیل، **تأیید حقوق مستند برای پردازش خارجی متن**، کلید Anthropic، فعال‌سازی صریح و سقف هزینه و یک تیک موافقت با ارسال متن به سرویس خارجی است. تنها یک فراخوانی برای هر تحلیل رخ می‌دهد؛ اگر قبلاً انجام شده باشد از همان audit استفاده می‌شود. در صورت تغییر منبع یا تحلیل، نتیجهٔ قدیمی به‌عنوان نتیجهٔ فعلی نشان داده نمی‌شود.
- API موجود `criteria_v2.engine_v207` برای درخواستِ شش‌معیاری و اعتبارسنجی سختگیرانهٔ شواهدِ کاملاً موجود در متن استفاده می‌شود؛ هیچ تماس پنج‌معیاری یا تبدیل امتیاز در کار نیست. متن قبل از ارسال از شناسه‌ها، ایمیل و شمارهٔ آشکار پاک‌سازی می‌شود (بدون تضمین حذف کامل شناسه‌های شخصی). متن خام و پاسخ API در پیام خطا و لاگ چاپ نمی‌شوند.
- نتیجهٔ مستقل Claude فقط پیشنهاد با وضعیت audit است: هرگز امتیاز GPT-6، دریافت مجوز، نوع تجربه، رأی کاربر یا انتشار شرکت را تغییر نمی‌دهد. اگر نوع روایت را متفاوت تشخیص دهد، نمرهٔ غیرهم‌نوعی را وارد جدول نمی‌کند.
- پس از migration و با تأیید مالک برای فراخوانی پولی، متغیرهای زیر را در محیط امن سرویس تنظیم کنید. **در استقرار، به‌صورت پیش‌فرض OFF است.**
  - `JOBIEW_CLAUDE_SIX_ENABLED=1`
  - `JOBIEW_CLAUDE_SIX_LIMIT=10` (حداکثر ۱۰۰؛ برای آزمایش عدد پایین‌تر انتخاب کنید)
  - `JOBIEW_CLAUDE_SIX_MODEL=claude-sonnet-5-5` (باید مدل واقعی مجاز حساب باشد)
  - `ANTHROPIC_API_KEY` از منبع امن secret سرور
- هزینهٔ واقعی به مدل، توکن‌ها، تنظیمات شرکت سازنده، وضعیت شبکه و سقف بستگی دارد؛ این نسخه پرداخت یا اعتبار Claude را خودکار تضمین نمی‌کند. اگر کلید یا مدل در سرویس در دسترس نباشد، به‌جای نمایش نتیجهٔ ساختگی پیام وضعیت نمایش داده می‌شود.

## اجرا و تست
- GitHub Actions: lint/smoke و Django SQLite همهٔ `criteria_v2`، و PostgreSQL تست‌های اصلی ۶+۶، پذیرش منبع و Claude/پنل ساده را با دادهٔ مصنوعی اجرا می‌کنند.
- این نسخه **migration جدید دارد** (`0006_claudesixcheck_v233`)؛ برخلاف نسخه‌های v2.0.27 تا v2.0.32، اجرای `manage.py migrate --noinput` بعد از تهیهٔ snapshot دیتابیس و قبل از restart ضروری است.
- مسیر امن نصب: پشتیبان‌گیری دیتابیس طبق دستورالعمل سرور، `git fetch/pull --ff-only`، `manage.py check`، `manage.py makemigrations --check --dry-run`، `manage.py migrate --noinput`، `manage.py collectstatic --noinput`، `jobiew-web restart`، مشاهدهٔ وضعیت اصلی. از غیرفعال‌کردن CSRF یا publication gates اجتناب کنید.
- پوشش test: ۶ معیار work/interview، عدم fallback به پنج معیار، دسترسی شرکت دیگر، عدم اجرای پولی بدون مجوز/تأیید، عدم اجرای تکراری، عدم انتشار خودکار و نگهداری نتیجه، وضعیت مرحله‌های شرکت و خصوصی‌بودن داده‌ها.

## باقی‌ماندهٔ صادقانه
پنل در این نسخه «ورود خودکار نظر از UI»، «اجرای زندهٔ GPT-6 برای تمام ۸٬۱۳۹ تجربه» و «زمان‌بندی/صف‌کاری غیربلاک‌کنندهٔ Claude» ندارد. کد فعلی API Claude با timeout محدود یک درخواست هم‌زمان در همان فرم اجرا می‌کند؛ برای حجم بالا، queue، retry مدیریت‌شده و ابزار ingest با قالب حقوقی جداگانه باید در مرحله‌ای مستقل طراحی شوند. این موارد را با حذف بررسی‌های قانونی یا استفاده از نتایج قدیمی پنج‌معیاری دور نزنید.
